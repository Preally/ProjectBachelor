Global parameterization enables you to generate like bearings in seconds. Download and see the _READ ME*.txt text file for instructions. Store models, global and integral parameters files, and _READ ME*.txt to the same directory, and re-link each model to the global parameters when prompted to do so (the first time you open any formerly linked model in SolidWorks).

Understand that if you download a subset of the library, you must also have the global parameters file (_params GLOBAL*.txt).
